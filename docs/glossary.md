# Słownik domenowy

Słownik domenowy (Domain Glossary) definiuje pojęcia używane w projekcie, aby wszyscy członkowie zespołu rozumieli je w ten sam sposób.

Pojęcia opisujemy językiem dziedziny, dla której tworzymy system, a nie językiem technologii.


## Pojęcia

| Pojęcie | Definicja |
|---|---|
| Użytkownik | osoba szukająca przepisu, dopasowanego do swoich wymagań kulinarnych |
| Składnik | Artykuł spożywczy |
| Skład | zbiór par postaci: składnik i jego ilość.|
| Instrukcja | Czynność, którą należy wykonać w ramach przepisu, może wymagać składników |
| Przepis | Skład i zbiór instrukcji (ich wykonanie prowadzi do powstania dania) |
| Danie | Obiekt powstały po zastosowaniu przepisu |
| Składnik niedopuszczalny | Składnik, który nie może znaleźć się w przepisie |
| Dieta | Zbiór składników niedopuszczalnych |
| Lodówka | Zbiór składników, które są dopuszczalne w przepisie |
| Wymagane składniki | Składniki, które muszą znaleźć się w przepisie |
| Styl gotowania | Zestaw instrukcji, które mogą znaleźć się w przepisie |
| Specyfika przepisu | Cecha przepisu mówiąca, czy jest on zgodny z określoną dieta, lodówką, wymaganymi składnikami, stylem gotowania |
| Kuchnia | Specyfika przepisu wskazująca na związek z danym regionem świata |
| Wymagania kulinarne | Specyfika przepisu, którą wybiera użytkownik (np. poprzez wybór kuchni) |
